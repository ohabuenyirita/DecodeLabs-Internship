## Technical Competencies Demonstrated

* **Data Engineering & Preparation:** Programmatic handling of missing values, string standardization, type casting, duplicate resolution, and outlier identification.
* **Exploratory Data Analysis (EDA):** Univariate and multivariate statistical analyses, distribution evaluations, correlation mapping, and trend detection.
* **Relational Database Management:** Writing structured T-SQL queries in SSMS using conditional filtering (`WHERE`), aggregate grouping (`GROUP BY`, `SUM`, `AVG`, `COUNT`), multi-level bucket filtering (`HAVING`), and query optimization.
* **Business Intelligence & Visualization:** Conceptualizing key performance metrics, relational data modeling, and designing interactive dashboards.
* **Documentation & Version Control:** Version control best practices via GitHub, modular project structuring, markdown technical writing, and reproducible code formatting.
